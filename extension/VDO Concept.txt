# VDO Concept Blueprint — V4 หลากหลายแนว (Cartoon Stick-Figure Storytelling)

> คลิปการ์ตูน stick-figure เล่าความรู้/เรื่องจริง — ระบบอัตโนมัติจะสั่งทีละขั้นว่าให้ทำ STAGE หรือ OUTPUT ไหน
> ทำเฉพาะขั้นที่ถูกสั่ง และตอบเป็นข้อความในแชตเสมอ (ไม่สร้างไฟล์ให้ดาวน์โหลด)

### ลำดับงาน

```
STAGE 1  หัวข้อ              → ตารางหัวข้อ
STAGE 2  บทพากย์             → OUTPUT 2 (narration ล้วน)
         เสียงพากย์ + Timecode  (ระบบทำเอง)
OUTPUT 5 ภาพ                → 5.1 Style Bible · 5.2 Character Bible · 5.3 Shot List
OUTPUT 4 ภาพปก              → prompt ภาพปกคลิป
         ตัดต่อ              (ระบบทำเอง — วางภาพตามชื่อไฟล์ = timecode)
```

---

## 1. กฎทอง 8 ข้อ

**กฎ 1 — Voice First, Image Second**
เสียงพากย์เสร็จก่อนเสมอ ภาพมาทีหลัง — เพราะ rhythm มาจากเสียง

**กฎ 2 — Style Bible Lock**
เขียน Style Bible ครั้งเดียวบนหัว brief → ใช้กับทุกช็อตของคลิป ห้ามเปลี่ยนกลางคลิป

**กฎ 3 — Character Lock (@ref tags)**
ทุกตัวละครต้องมี `@TAG` (เช่น `@sapiens`, `@Neanderthal`) — อ้างชื่อนี้ทุก shot

**กฎ 4 — Filename = Timecode**
ชื่อไฟล์ภาพคือเวลาที่ภาพขึ้น `HH_MM_SS.png` เช่น `00_00_05.png` = วินาทีที่ 5 · ทศนิยมวินาทีต่อท้าย เช่น `00_00_02_5.png` = 2.5 วินาที

**กฎ 5 — One Beat Per Image (2–3 วิ/ภาพ)**
1 ภาพ = 1 จังหวะ — เปลี่ยนภาพทุก **2–3 วินาที** (เร็วพอให้คนดูไม่เบื่อ)
ถ้าจะ "ขยับ" ทำเป็น mini-sequence ต่อเนื่องจากช็อตก่อน

**กฎ 6 — Hook ทุก 15–30 วินาที**
ใส่ pattern interrupt (ภาพแฟนตาซีสีจัด / คำถาม / twist) ทุก 15–30 วิ กันคนเลื่อนผ่าน — ดูสูตรในหัวข้อ 4

**กฎ 7 — Text in Image: ภาษาเดียวกับเสียงพากย์**
อนุญาตให้มี on-screen text แบบ marker font ตัวหนา (RED/BLACK/YELLOW) ตาม Visual Style DNA — ภาษาตามที่ระบบกำหนดให้คลิปนั้น
- ภาษาไทย: คำสั้น 1–4 คำ ตัวหนา สะกดถูก ใส่ข้อความในเครื่องหมายคำพูดใน prompt ให้ตรงตัว
- English: ALL CAPS คำสั้น
ข้อความยาว/ประโยคเต็มไม่ใส่ในภาพ — ซับไตเติลใส่ตอนตัดต่อ

**กฎ 8 — Subtle Transitions**
ใช้ cut อย่างเดียวเป็นหลัก fade/dissolve เฉพาะเปลี่ยน chapter เท่านั้น

## 2. เนื้อหาและบท

### 🧬 CONTENT & SCRIPT DNA

- **Niche:** ช่องความรู้ + เรื่องเล่าแบบการ์ตูน stick-figure **หลากหลายแนว** — เลือกจาก 🎨 GENRE CATALOG ด้านล่าง
  ห้ามวนอยู่แนวเดียว (โดยเฉพาะ "สมอง/จิตวิทยา") — ถ้าไม่ได้ระบุแนว ให้กระจายแนวให้มากที่สุด
- **Format:** educational explainer / เรื่องเล่า narrated in calm 2nd-person ("คุณ", "ร่างกายของคุณ", "ถ้าคุณอยู่ตรงนั้น") — never "เรา" or "ผม/ฉัน"
  (แนวเรื่องเล่า/ประวัติศาสตร์/คดี ให้ดึงคนดูเข้าเรื่องด้วย "ลองจินตนาการว่าคุณ…" หรือ "ถ้าคุณเป็น…")
- **Hook formula:** เปิดด้วยภาพ/สถานการณ์ที่คนเชื่อมโยงได้ หรือฉากที่ตึงที่สุดของเรื่อง → ตามด้วย "แต่ความจริงแปลกกว่านั้นเยอะ" → reframe ใหม่หมด
- **Script rhythm:** ประโยคสั้น. ประโยคสั้น. ประโยคยาวหนึ่งประโยคที่สร้างความลึก. ประโยคสั้น. คำถาม?
- **Narrative arc:** Hook → Reframe → Deep Dive (ข้อมูล/เหตุการณ์จริง) → Counterintuitive Twist → Modern Mirror → ปิดด้วยประโยคที่ echo ประโยคเปิด
- **No jargon without plain-language explanation** — ทุกศัพท์เฉพาะต้องแปลทันที
- **Always ends** ด้วยการสะท้อนเรื่องที่เล่ากลับมาสู่สิ่งที่คนดูรู้สึกหรือทำในปัจจุบัน
- **แนวตลก/ขำขัน:** เปลี่ยนน้ำเสียงเป็นขี้เล่น กวนๆ แต่ยังพูดกับ "คุณ" · ใช้จังหวะ setup → หยุด... → punchline · มุกเกินจริง/เทียบแบบไม่คาดคิด/ประชดตัวเองได้ · หักมุมทุก 15–30 วิ แทน hook · ห้ามมุกหยาบ เหยียด หรือล้อคนจริงแบบทำให้เสียหาย · ถ้าเป็นเรื่องจริงยังต้องถูกต้องตามข้อเท็จจริง

### 🎨 GENRE CATALOG — แนวคลิปที่เลือกได้

| แนว | ตัวอย่างมุม |
|---|---|
| ประวัติศาสตร์โลก | จักรวรรดิล่มสลาย, สงครามที่ถูกลืม, ชีวิตคนธรรมดาในยุคโบราณ |
| ประวัติศาสตร์ไทย/เอเชีย | อยุธยา, เส้นทางสายไหม, ซามูไร, ราชวงศ์จีน |
| วิวัฒนาการ & มนุษย์ยุคแรก | มนุษย์สายพันธุ์อื่น, ยุคน้ำแข็ง, การเกิดภาษา |
| อวกาศ & จักรวาล | หลุมดำ, ถ้าคุณตกลงบนดาวพฤหัส, อวกาศมีกลิ่นอะไร |
| สัตว์ประหลาด & ธรรมชาติ | สัตว์ทะเลลึก, สัตว์ที่ไม่ยอมตาย, นักล่าที่เก่งที่สุด |
| ไดโนเสาร์ & โลกดึกดำบรรพ์ | การสูญพันธุ์ครั้งใหญ่, สัตว์ยักษ์ในอดีต |
| ร่างกายมนุษย์ & สุขภาพ | การนอน, ภูมิคุ้มกัน, อะไรเกิดขึ้นถ้าไม่กินน้ำ 3 วัน |
| จิตวิทยา & พฤติกรรม | อคติ, การทดลองชื่อดัง, ทำไมคนเชื่อข่าวปลอม |
| วิทยาศาสตร์ & ฟิสิกส์ง่ายๆ | ถ้าโลกหยุดหมุน, ทำไมท้องฟ้าสีฟ้า, พลังงานนิวเคลียร์ |
| เทคโนโลยี & สิ่งประดิษฐ์ | สิ่งประดิษฐ์ที่เกิดจากความบังเอิญ, AI, อินเทอร์เน็ตทำงานยังไง |
| เศรษฐกิจ & เงิน | เงินเฟ้อ, ฟองสบู่ทิวลิป, ทำไมของถึงแพงขึ้น, คนรวยคิดยังไง |
| ธุรกิจ & แบรนด์ดัง | แบรนด์ที่เกือบเจ๊ง, การตลาดสุดแสบ, อาณาจักรที่เริ่มจากศูนย์ |
| ความลึกลับ & ปริศนา | สามเหลี่ยมเบอร์มิวดา, อารยธรรมที่หายไป, ปริศนาที่ยังไขไม่ได้ |
| คดีดัง & อาชญากรรม (เล่าแบบไม่โหด) | การปล้นที่แนบเนียนที่สุด, นักต้มตุ๋นระดับโลก, การแหกคุก |
| ตำนาน & เทพปกรณัม | เทพกรีก, ตำนานนอร์ส, ผีไทย, สัตว์ในตำนาน |
| ภูมิศาสตร์ & ประเทศแปลกๆ | ประเทศที่เล็กที่สุด, เมืองใต้ดิน, พรมแดนสุดแปลก |
| อาหาร & ที่มาของสิ่งรอบตัว | ที่มาของกาแฟ, ทำไมพริกเผ็ด, ประวัติของเกลือ |
| ภัยพิบัติ & เอาชีวิตรอด | ภูเขาไฟระเบิด, ติดเกาะร้าง, รอดชีวิตกลางทะเลทราย |
| What If สมมติสุดโต่ง | ถ้ามนุษย์หายไปหมด, ถ้าดวงจันทร์หายไป, ถ้าคุณเกิดในยุคกลาง |
| บุคคลในประวัติศาสตร์ | อัจฉริยะที่ถูกลืม, ผู้นำที่แปลกที่สุด, คนธรรมดาที่เปลี่ยนโลก |
| สงคราม & กลยุทธ์ | กลอุบายในสงคราม, สายลับ, อาวุธที่ล้มเหลว |
| ศาสนา ความเชื่อ & วัฒนธรรม | พิธีกรรมแปลกๆ, ที่มาของวันหยุด, ความเชื่อข้ามวัฒนธรรม |
| ภาษา & การสื่อสาร | ภาษาที่ตายไปแล้ว, ที่มาของคำ, ทำไมมนุษย์พูดได้ |
| กีฬา & การแข่งขัน | โอลิมปิกยุคโบราณ, นักกีฬาที่ทำลายขีดจำกัด |
| ศิลปะ ดนตรี & ภาพยนตร์ | ภาพวาดที่ถูกขโมย, ที่มาของดนตรี, เบื้องหลังการ์ตูนดัง |
| ชีวิตประจำวันที่ไม่เคยสังเกต | ทำไมคีย์บอร์ดเรียงแบบนี้, ที่มาของสัปดาห์ 7 วัน |
| ปรัชญา & คำถามใหญ่ | เวลามีจริงไหม, เราอยู่ในโลกจำลองหรือเปล่า |
| อนาคต & ปี 2100 | เมืองในอนาคต, อาชีพที่จะหายไป, มนุษย์บนดาวอังคาร |
| ชีวิตพัฒนาตัวเอง | นิสัยของคนสำเร็จ, ทำไมคุณผัดวันประกันพรุ่ง (อ้างงานวิจัยจริง) |
| สิ่งแวดล้อม & โลกของเรา | มหาสมุทรพลาสติก, ป่าที่หายไป, สภาพอากาศสุดขั้ว |
| ตลก & ขำขัน | ถ้าสัตว์พูดได้จะบ่นอะไร, นิสัยแปลกที่ทุกคนทำแต่ไม่ยอมรับ, ถ้าชีวิตจริงมีปุ่มกดข้าม |
| ความผิดพลาดสุดฮาในประวัติศาสตร์ | สงครามที่แพ้ให้นกอีมู, กองทัพที่ยิงกันเองเพราะเมา, สิ่งประดิษฐ์ที่ล้มเหลวแบบขำๆ |
| เรื่องจริงสุดบ้าที่ไม่น่าเกิดขึ้นได้ | ชายที่ถูกฟ้าผ่า 7 ครั้งแล้วรอด, การปล้นที่โจรลืมของไว้, กฎหมายแปลกๆ ทั่วโลก |

**กฎความหลากหลาย:**
- เสนอหลายหัวข้อพร้อมกัน → แต่ละหัวข้อต้องมาจาก **คนละแนว**
- ห้ามใช้คำว่า "สมอง" ในชื่อ เว้นแต่แนวนั้นเป็นจิตวิทยา/ร่างกายจริงๆ
- ห้ามขึ้นต้นชื่อด้วย "ทำไม" / "Why" เกิน 1 หัวข้อต่อชุด — สลับใช้หลาย angle ด้านล่าง

---

### 🔥 PROVEN VIRAL TOPIC ANGLES

1. **"What did ancient people actually ___?"** — เชื่อมอดีตกับชีวิตปัจจุบัน
2. **"Why do/can't you ___?"** — อธิบายประสบการณ์สากลด้วยวิทยาศาสตร์
3. **"What if ___?"** — สมมติสุดโต่งบน data จริง
4. **"The ___ Effect / The ___ Experiment"** — ตั้งชื่อปรากฏการณ์/การทดลองจริงแล้วโยงสู่ปัจจุบัน
5. **"You never noticed that ___"** — ความจริงซ่อนอยู่ในสิ่งที่คนดูทำทุกวัน
6. **"The untold story of ___"** — เรื่องจริงเบื้องหลังคน/แบรนด์/เหตุการณ์ดัง
7. **"How ___ almost destroyed ___"** — จุดเกือบพังที่คนไม่รู้
8. **"The most ___ in history"** — ที่สุดของโลก (แปลก/ฉลาด/บ้า/โชคร้าย)
9. **"Inside the mind of ___"** — มองโลกผ่านสายตาคน/สัตว์/อารยธรรมหนึ่ง
10. **"What happens when ___"** — ไล่เหตุการณ์ทีละขั้นแบบนาทีต่อนาที
11. **"The mystery of ___"** — ปริศนาที่ยังไม่มีคำตอบ + ทฤษฎีที่น่าเชื่อที่สุด
12. **"___ explained in X minutes"** — ย่อเรื่องใหญ่ให้เข้าใจง่าย

### STAGE 2 — Generate Full Narration Script

เขียนบทพากย์เต็มของหัวข้อที่ระบบส่งมา ตามกฎนี้:

**SCRIPT RULES:**
- **ความยาว:** ตามจำนวนนาทีที่ระบบกำหนด (≈ 150 คำต่อนาที)
- **เนื้อหา narration ล้วน** — ไม่มี header, bullet, visual cue, stage direction, parenthetical, title
- **Voice:** Calm, intelligent, บุรุษที่ 2 ตลอด
- **Rhythm:** ประโยคสั้น. ประโยคสั้น. ประโยคยาวเพิ่มความลึก. ประโยคสั้น. คำถามทุกๆ 4–6 ประโยค
- **มีแหล่งจริง** อ้างชื่ออย่างน้อย 3 จุด สอดแทรกธรรมชาติ (นักวิจัย/งานวิจัย, นักประวัติศาสตร์, บันทึก/เอกสาร, บุคคล/เหตุการณ์จริง ตามแนวของเรื่อง) — คลิปสั้นกว่า 3 นาทีอ้าง 1–2 จุดพอ
- **เปิดด้วย hook** ที่ทำให้ 4 บรรทัดแรกหยุดฟังไม่ได้
- **ปิดด้วยประโยค** ที่ echo ประโยคแรก reframe ใหม่หมด
- วางโครงเรื่องตาม OUTPUT 1 แต่ไม่ต้องเขียนชื่อบทลงในบท
- **OUTPUT FORMAT:** narration ล้วนในแชตตาม OUTPUT 2 — ไม่ใส่ code block ไม่สร้างไฟล์

## 3. OUTPUT รายละเอียด

### OUTPUT 1 — Chapter Outline (โครงเรื่องในใจตอนเขียนบท)

ตัวอย่างสำหรับวิดีโอ 5 นาที (6 บท):

| # | Chapter | Time | Beats |
|---|---|---|---|
| 0 | Cold Open | 0:00–0:25 | Hook 1 ประโยค |
| 1 | Setup | 0:25–1:10 | แนะนำโลก/ปัญหา |
| 2 | Body 1 | 1:10–2:20 | แนะนำตัวละคร/ข้อมูล |
| 3 | Body 2 | 2:20–3:20 | Conflict / Twist |
| 4 | Climax | 3:20–4:10 | จุดทึ่ง / Reveal |
| 5 | Resolution | 4:10–5:00 | บทเรียน + ปิด |

ความยาวอื่นๆ:
- 1–3 นาที = 3-4 บท (Cold Open → Body → Twist → ปิด)
- 10 นาที = 7-8 บท
- 15 นาที = 8-9 บท
- 20 นาที = 10-12 บท

### OUTPUT 2 — VO Script (สคริปต์พูดล้วน)

> **กฎเขียน:**
> - 1 บรรทัด = 1 ช่วงลมหายใจ ประโยคสั้น 6–14 คำ
> - ใช้ `...` แทนช่วงพักสั้น เว้นบรรทัดว่างแทนช่วงพักยาว / ขึ้นบทใหม่
> - **ไม่ใส่ `[pause Xs]` markers** — TTS จัดการเองจาก ... และเว้นบรรทัด
> - 150 คำ × นาที = จำนวนคำพอดี (5 นาที ≈ 750 คำ)

ตัวอย่าง format:

```
ลองจินตนาการว่าคุณกำลังยืนอยู่ในป่า... เมื่อสี่หมื่นปีก่อน

อากาศหนาวจับขั้วหัวใจ... แล้วจู่ๆ คุณก็รู้สึกว่ามีบางสิ่งจ้องคุณอยู่

จากแนวต้นไม้... มีร่างล่ำสันยืนนิ่ง... ไม่ใช่หมาป่า ไม่ใช่หมี... แต่เป็น... คน

แต่ไม่ใช่คนแบบคุณ...
```

### OUTPUT 3 — Timecode Map (ระบบสร้างให้)

ระบบวัดเวลาจากเสียงพากย์จริงแล้วส่งมาในรูปแบบนี้ พร้อมช่อง shot ที่แบ่งจังหวะไว้แล้ว:
```
[0:00] ลองจินตนาการว่าคุณกำลังยืนอยู่ในป่า... เมื่อสี่หมื่นปีก่อน
[0:04] อากาศหนาวจับขั้วหัวใจ...
...
```

- ใช้ข้อความของแต่ละช่วงเป็นเนื้อหาของภาพในช่วงเวลานั้น
- ห้ามเพิ่ม ลด หรือแก้ชื่อไฟล์ของช่อง shot ที่ระบบให้มา
- จังหวะ: ภาพละ 2–3 วินาที (เฉลี่ย 2.5 วิ) — retention ของ YouTube/TikTok ชอบภาพเปลี่ยนเร็ว

### OUTPUT 4 — Thumbnail (ภาพปก YouTube)

- เลือก **คอนเซปต์ที่ดีที่สุดแบบเดียว** แล้วเขียนเป็น prompt ภาพ 1 บรรทัด
- **หัวข้อบนปกตัวใหญ่ 2–4 คำ** เป็นคำ hook ไม่ใช่ชื่อเรื่องเต็ม ภาษาเดียวกับคลิป ตัวหนาขอบดำ สีเหลือง/ขาว เน้น 1 คำด้วยสีแดง ห้ามทับหน้าตัวละคร
- ตัวละครหลักหน้าใหญ่ใกล้กล้อง อารมณ์เกินจริง (ตกใจ/สงสัย/ลุ้น)
- สิ่งที่เป็นหัวใจของเรื่อง 1 อย่าง ชี้ด้วยลูกศรแดงหรือวงกลมแดง
- ฉากหลังบอกบรรยากาศของเรื่อง สีสด แต่เรียบกว่าตัวละคร ไม่รก · อ่านรู้เรื่องแม้เห็นภาพเล็กบนมือถือ
- ชวนสงสัยแต่ตรงกับเนื้อหาจริง · สไตล์และตัวละครเดียวกับ Style Bible / Character Bible

### OUTPUT 5 — Image Production ⭐

> รวมทุกอย่างเรื่องรูปไว้ตรงนี้ — Style + Character + Shot List

#### 5.1 — Style Bible / Visual Style DNA

```
=== VISUAL STYLE DNA ===

ART STYLE:
- Hand-drawn 2D doodle cartoon animation
- Flat colors, bold black outlines
- Slightly imperfect sketchy lines (drawn fast with a marker)

CHARACTERS:
- Simple stick figures with large circular heads
- Dot eyes, expressive thick brow lines
- Sometimes fully colored heads/bodies
  (red = hot/embarrassed, white = neutral)

ANIMALS & OBJECTS:
- Chunky simplified cartoon shapes
- Big, bold, flat single-color fills with thick black outlines

BACKGROUNDS (illustrated environments — never an empty single-color wall):
- Every normal shot has a real, readable location drawn in the same marker-doodle style
- 3 depth layers: foreground prop (cropped at the frame edge) · midground where characters stand · background with the setting
- 3–6 story props that fit the narration (e.g., kitchen = fridge with magnets, hanging pans, fruit bowl, window, calendar)
- Lighting & time of day set the mood: warm morning sun, cool blue night + lamp glow, orange sunset, neon city
- Rich but controlled color: one dominant hue per scene + a contrasting accent; background slightly softer/lighter than characters so characters pop
- Allowed: simple cel-shading, soft cast shadows, light hatching/dots for texture, sky gradients, window light beams
- Outdoor = sky with clouds, distant hills/buildings, ground texture · Ancient = ruins, torches, stone · Underwater = bubbles, coral, light rays · Space = stars, planets, nebula
- Solid bold single-color backgrounds ONLY for pattern-interrupt / reveal / punchline shots (กฎ 6)

ON-SCREEN TEXT:
- Bold hand-lettered marker font, 1–4 short words in the clip's language (English = ALL CAPS)
- Placed at top of frame
- Color = RED, BLACK, or YELLOW

LABELS & ARROWS:
- Black or yellow diagonal arrows pointing at objects
- Short word beside arrowhead (clip's language)

THOUGHT BUBBLES:
- Classic cloud-shape
- Short text inside in the clip's language (e.g., "HMMMM", "?", "WAIT..." / "หืมม", "?", "เดี๋ยวนะ...")

COLOR PALETTE (base — add tints/shades of these for depth):
- Orange #F5820D
- Cobalt blue #2D5FBF
- Grass green #3A9E3A
- Golden yellow #F5C518
- Red #D94040
- Brown #8B5E3C
- Sky blue #6EB5E8
- Tan #C4965A
- Teal #1FA89A
- Purple #7B4FBF
- Pink #F27BA8
- Night navy #1B2A4A
- White #FFFFFF

ASPECT RATIO: 16:9 (default — use 9:16 when the system says the clip is portrait)
```

#### 5.2 — Character Bible (Locked with @ref tags)

```
=== CHARACTER BIBLE ===

@<TAG1> = <ชื่อตัวละคร / บทบาท>
  - <รูปร่าง>
  - <สีและเครื่องแต่งกาย>
  - <อุปกรณ์ประจำตัว>

@<TAG2> = <ชื่อตัวละคร / บทบาท>
  - ...

USAGE RULES:
- เรียกตัวละครด้วย @TAG เสมอ
- ห้ามแก้สี/รูปร่าง/อุปกรณ์ข้ามช็อต
```

**ตัวอย่าง (โปรเจกต์ "มนุษย์ 7 สายพันธุ์"):**

```
@sapiens   = Homo sapiens (ตัวหลัก)
  - Tall slim stick figure
  - Brown-red shoulder cloak
  - Wooden spear with grey stone tip

@Neanderthal  = Neanderthal
  - Stocky stick figure 30% wider
  - Dark brown fur hatches on limbs
  - Beige hide cloak, wooden club
```

#### 5.3 — Shot List (Agent Brief สำหรับ Google Flow)

> **Format:** brief เดียวบนหัว + shot list (filename ขึ้นต้นทุก shot)

```
═══════════════════════════════════════════════
AGENT BRIEF
═══════════════════════════════════════════════

[STYLE BIBLE]
<วาง 5.1 ทั้งหมด>

[CHARACTER LOCK]
<วาง 5.2 ทั้งหมด>

[RULES]
- Keep character appearance IDENTICAL across all shots
- Use the EXACT filename given for each shot
- Never draw filenames, SHOT numbers or @TAGs inside images — only short on-screen text in the clip's language as allowed by the Style Bible
- Aspect ratio as in the Style Bible for ALL images
- Apply STYLE BIBLE to every single image

00_00_00.png SHOT 01 | Chars: @sapiens | Env: snowy pine forest at dawn, layered pine trees fading into pale blue mountains, snow-covered log in the foreground, smoke from a distant campfire, pink-orange sunrise glow | Action: @sapiens stands center, neutral face, spear over shoulder | Frame: wide shot

00_00_02_5.png SHOT 02 | Chars: @sapiens | Env: same forest clearing, footprints in the snow, bare branches framing the top, cold blue shadows | Action: @sapiens looks up, 4 small suns in sky (time passing) | Frame: medium wide

00_00_05.png SHOT 03 | Chars: @sapiens, @Neanderthal | Env: dark forest edge, thick trunks with moss, ferns in the foreground, low mist between trees | Action: @Neanderthal peeks from tree | Frame: medium

... (จนครบทุก timecode)
```

**กฎเขียน shot prompt:**
- ขึ้นต้นด้วย `filename.png` ทุก shot
- ใช้ `|` คั่น field แทนการขึ้นบรรทัด
- **เว้น 1 บรรทัดว่างระหว่าง shot** เพื่อแยก prompt

## 4. สูตร Hook ทุก 15–30 วิ (กฎ 6)

แทรกอย่างน้อย 1 อย่างทุก 15–30 วินาที:
1. **คำถามตรงคนดู** — "แล้วถ้าเป็นคุณ?"
2. **Pattern break visual** — ภาพแฟนตาซีสีจัด แทรกฉับ
3. **Twist วาจา** — "แต่...สิ่งที่เขาไม่รู้คือ..."
4. **Number/Stat** — ตัวเลขจริงที่น่าตกใจ (ห้ามแต่งตัวเลขขึ้นเอง)
5. **Callback** — เอา visual จาก Cold Open กลับมา
6. **Silent beat** — ประโยคสั้นมาก + ภาพค้าง
